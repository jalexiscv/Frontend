Select

El componente Select genera elementos select HTML con opciones desde un array asociativo. Soporta selected, disabled, required, y multiple.

Codigo PHP

PHP
echo $bootstrap->select([
    'name'     => 'pais',
    'label'    => 'Pais de Residencia',
    'options'  => [
        ''   => 'Seleccione una opcion...',
        'mx' => 'Mexico',
        'co' => 'Colombia',
        'ar' => 'Argentina',
        'es' => 'Espana',
        'pe' => 'Peru',
    ],
    'selected' => 'co',
    'required' => true,
])->render();

Resultado

Opciones del Constructor

OpcionTipoDefaultDescripcion

idstring—Identificador HTML del elemento.
labelstring—Etiqueta descriptiva del campo.

selectedstring—Valor de la opcion seleccionada por defecto.
requiredboolfalseMarca el campo como obligatorio.
disabledboolfalseDeshabilita el campo.
multipleboolfalsePermite seleccion multiple.
sizeint—Numero de opciones visibles en modo multiple.
