Textarea

El componente Textarea genera campos de texto multilinea con control de filas, maxlength y texto de ayuda.

Codigo PHP

PHP
echo $bootstrap->textarea([
    'name'      => 'descripcion',
    'id'        => 'descripcion',
    'label'     => 'Descripcion del Producto',
    'rows'      => 4,
    'maxlength' => 500,
    'value'     => 'Texto preexistente en el area...',
    'helpText'  => 'Maximo 500 caracteres.',
    'required'  => true,
])->render();

Resultado

Maximo 500 caracteres.

Opciones del Constructor

OpcionTipoDefaultDescripcion

disabledboolfalseDeshabilita el campo.
