Input

El componente Input genera campos de formulario de todos los tipos HTML: text, email, password, number, date, color, range, file, etc. Incluye label, placeholder, helpText, feedback y validacion.

Codigo PHP

PHP
echo $bootstrap->input([
    'type'        => 'text',
    'name'        => 'username',
    'id'          => 'username',
    'placeholder' => 'Ingrese su usuario',
    'label'       => 'Nombre de Usuario',
    'value'       => 'jalexiscv',
    'required'    => true,
    'helpText'    => 'Minimo 4 caracteres.',
])->render();

echo $bootstrap->input([
    'type'        => 'email',
    'name'        => 'email',
    'label'       => 'Correo Electronico',
    'placeholder' => 'correo@ejemplo.com',
])->render();

Resultado

Minimo 4 caracteres.

Opciones del Constructor

OpcionTipoDefaultDescripcion
typestringtextTipo de input HTML: text, email, password, number, date, color, range, file, tel, url, search, datetime-local, month, week, time, hidden.
namestring—Atributo name del campo.
idstring—Identificador HTML del elemento.
labelstring—Etiqueta descriptiva del campo.
placeholderstring—Texto de sugerencia dentro del campo.
valuestring—Valor inicial del campo.
requiredboolfalseMarca el campo como obligatorio.
disabledboolfalseDeshabilita el campo.
readonlyboolfalseSolo lectura, el valor no puede modificarse.
helpTextstring—Texto de ayuda debajo del campo.
feedbackstring—Mensaje de validacion (rojo si es invalido, verde si es valido).
classstring—Clases CSS adicionales.
