InputGroup

El componente InputGroup combina inputs con texto, iconos o botones como prepend/append. Ideal para @usernames, montos con $, busquedas con boton.

Codigo PHP

PHP
echo $bootstrap->inputGroup([
    'prepend' => '@',
    'input'   => $bootstrap->input([
        'name'        => 'usuario',
        'placeholder' => 'Nombre de usuario',
    ]),
    'append' => $bootstrap->button([
        'content' => 'Buscar',
        'variant' => 'primary',
    ]),
])->render();

Opciones del Constructor

OpcionTipoDefaultDescripcion
prependstring|component—Contenido antes del input. Puede ser texto plano o un componente Higgs (icono, boton, etc.).
inputcomponent—Componente de input que va en el centro del grupo.
appendstring|component—Contenido despues del input. Puede ser texto plano o un componente Higgs (icono, boton, etc.).
sizestring—Tamano del grupo: lg, sm.
classstring—Clases CSS adicionales para el contenedor.
idstring—Identificador HTML del contenedor.
