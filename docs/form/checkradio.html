Check / Radio

Los componentes Check y Radio generan checkboxes, switches y radio buttons con labels. Check soporta modo switch. Radio soporta grupos para seleccion unica.

Codigo PHP

PHP
// Checkbox switch
echo $bootstrap->check([
    'label'   => 'Acepto los terminos y condiciones',
    'name'    => 'terms',
    'id'      => 'terms',
    'checked' => true,
    'switch'  => true,
])->render();

// Radio buttons
echo $bootstrap->radio([
    'name'    => 'plan',
    'label'   => 'Plan Premium',
    'value'   => 'premium',
    'checked' => true,
])->render();
echo $bootstrap->radio([
    'name'    => 'plan',
    'label'   => 'Plan Basico',
    'value'   => 'basico',
])->render();
