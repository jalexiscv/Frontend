Table

El componente Table genera tablas HTML con soporte para striped, hover, bordered, compact, responsive y header automatico desde arrays PHP.

Codigo PHP

PHP
$data = [
    ['#', 'Nombre', 'Email', 'Rol'],
    ['1', 'Ana Garcia', 'ana@email.com', 'Admin'],
    ['2', 'Carlos Ruiz', 'carlos@email.com', 'Editor'],
    ['3', 'Maria Lopez', 'maria@email.com', 'Viewer'],
];

echo $bootstrap->table([
    'data'      => $data,
    'striped'   => true,
    'hover'     => true,
    'responsive'=> true,
    'header'    => true,
    'class'     => 'table-sm',
])->render();

Resultado

# Nombre Email Rol
1 Ana Garcia ana@email.com Admin
2 Carlos Ruiz carlos@email.com Editor
3 Maria Lopez maria@email.com Viewer

Opciones del Constructor

OpcionTipoPredeterminadoDescripcion
dataarray[]Array bidimensional con los datos de la tabla
stripedboolfalseAplica filas con fondo alternado (table-striped)
hoverboolfalseResalta la fila al pasar el cursor (table-hover)
borderedboolfalseAgrega bordes a todas las celdas (table-bordered)
compactboolfalseReduce el padding de las celdas (table-sm)
responsiveboolfalseHace la tabla responsiva con scroll horizontal
headerboolfalseConvierte la primera fila del array en <thead>
classstring''Clases CSS adicionales
idstring''Atributo id HTML
