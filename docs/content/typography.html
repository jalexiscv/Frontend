Typography

El componente Typography genera elementos de texto HTML con escape automatico XSS. Soporta h1-h6, p, lead, mark, del, u, small, strong, em.

Codigo PHP

PHP
use Higgs\Frontend\Frontend;
$frontend = new Frontend('bootstrap', '5.3.3');
$bootstrap = $frontend->get_Builder();

echo $bootstrap->typography([
    'tag'     => 'h1',
    'content' => 'Titulo Principal',
    'class'   => 'display-4',
])->render();

echo $bootstrap->typography([
    'tag'     => 'p',
    'content' => 'Parrafo con texto estilizado.',
    'class'   => 'lead',
])->render();

Opciones del Constructor

OpcionTipoPredeterminadoDescripcion
tagstring'p'Etiqueta HTML: h1-h6, p, lead, mark, del, u, small, strong, em
contentstring''Contenido de texto (escapado automaticamente contra XSS)
classstring''Clases CSS adicionales (display-4, lead, text-muted, etc.)
idstring''Atributo id HTML
