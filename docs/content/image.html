Image

El componente Image genera etiquetas img con soporte para redondeo, miniaturas, fluid y clases de alineacion.

Codigo PHP

PHP
echo $bootstrap->image([
    'src'     => '/img/photo.jpg',
    'alt'     => 'Descripcion de la imagen',
    'rounded' => true,
    'class'   => 'img-fluid',
])->render();

echo $bootstrap->image([
    'src'      => '/img/avatar.jpg',
    'alt'      => 'Avatar',
    'thumbnail'=> true,
    'class'    => 'rounded-circle',
    'width'    => 150,
])->render();

Resultado

img-fluid + rounded

thumbnail + rounded-circle (150x150)

img-thumbnail (200x200)

Opciones del Constructor

OpcionTipoPredeterminadoDescripcion
srcstring''URL de la imagen
altstring''Texto alternativo para accesibilidad
roundedboolfalseAplica bordes redondeados con .rounded
thumbnailboolfalseEnmarca la imagen como miniatura con .img-thumbnail
fluidboolfalseHace la imagen responsiva con max-width: 100%
classstring''Clases CSS adicionales
idstring''Atributo id HTML
widthintnullAncho de la imagen en pixeles
heightintnullAlto de la imagen en pixeles
