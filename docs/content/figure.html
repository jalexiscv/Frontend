Figure

El componente Figure genera el elemento figure de HTML5 con imagen y figcaption para descripcion semantica.

Codigo PHP

PHP
echo $bootstrap->figure([
    'image'   => '/img/diagram.jpg',
    'caption' => 'Figura 1: Diagrama de Arquitectura del Sistema',
    'alt'     => 'Diagrama arquitectonico',
    'class'   => 'text-center',
])->render();

Resultado

Opciones del Constructor

OpcionTipoPredeterminadoDescripcion
imagestring''URL de la imagen dentro del figure
captionstring''Texto del figcaption para describir la figura
altstring''Texto alternativo de la imagen para accesibilidad
classstring''Clases CSS adicionales (text-center, etc.)
idstring''Atributo id HTML
