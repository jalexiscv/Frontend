Indicator

El componente Indicator muestra puntos de estado con variantes de color y opcion de pulso animado. Util para indicar online/offline, estado de sistemas o notificaciones.

Codigo PHP

PHP
echo $bootstrap->indicator([
    'variant' => 'success',
    'pulse'   => true,
    'label'   => 'Online',
    'size'    => 'md',
])->render();

Resultado

Online Online Offline Away Unknown

Variantes disponibles: success, danger, warning, info, primary, secondary, dark, light

Opciones del Constructor

OpcionTipoDescripcionDefault
