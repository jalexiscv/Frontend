Icon

El componente Icon renderiza iconos de FontAwesome, Material Icons u otras librerias. Soporta tamaños, estilos (solid/regular/brands) y colores via clases CSS.

Codigo PHP

PHP
echo $bootstrap->icon([
    'name'    => 'user',
    'library' => 'fontawesome',
    'style'   => 'solid',
    'size'    => 'lg',
    'class'   => 'text-primary',
])->render();

echo $bootstrap->icon([
    'name'    => 'star',
    'library' => 'fontawesome',
    'style'   => 'solid',
    'size'    => '2x',
    'class'   => 'text-warning',
])->render();
