Tabs

El componente Tabs extiende Nav con paneles de contenido asociados. Cada pestana tiene su propio panel con soporte para animacion fade y carga dinamica.

Codigo PHP

PHP
echo $bootstrap->tabs([
    'items' => [
        ['title' => 'Datos', 'content' => 'Panel de datos principal...'],
        ['title' => 'Config', 'content' => 'Opciones de configuracion...'],
        ['title' => 'Logs', 'content' => 'Registro de actividad...'],
    ],
    'active' => 0,
    'fade'   => true,
])->render();

Resultado

Panel de datos principal con informacion relevante del sistema.
Opciones de configuracion del modulo actual.
Registro de actividad y eventos del sistema.
