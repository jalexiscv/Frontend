Progress

El componente Progress genera barras de progreso con variantes, modo striped, animacion y etiqueta de porcentaje.

Codigo PHP

PHP
echo $bootstrap->progress([
    'value'    => 75,
    'label'    => '75%',
    'variant'  => 'success',
    'striped'  => true,
    'animated' => true,
    'height'   => '20px',
])->render();

Resultado

75%
45%
60%
90%
100%
