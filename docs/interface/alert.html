Alert

El componente Alert muestra mensajes de retroalimentacion. Soporta variantes success, danger, warning, info, primary, secondary. Puede ser dismissible y acepta iconos via Html::raw().

Codigo PHP

PHP
$alert = $bootstrap->alert([
    'content'     => 'Operacion completada con exito!',
    'type'        => 'success',
    'dismissible' => true,
    'class'       => 'shadow-sm',
])->render();

echo $alert;

Resultado

Operacion completada con exito!
Error al procesar la solicitud.
Advertencia: El disco esta casi lleno.
Nueva actualizacion disponible.
