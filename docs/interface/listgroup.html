ListGroup

El componente ListGroup genera listas de items con soporte para badges, variantes de color, estados active/disabled y modo flush.

Codigo PHP

PHP
echo $bootstrap->listGroup([
    'items' => [
        ['content' => 'Item activo', 'active' => true],
        ['content' => 'Con badge', 'badge' => '5', 'badgeVariant' => 'primary'],
        ['content' => 'Item deshabilitado', 'disabled' => true],
        ['content' => 'Item success', 'variant' => 'success'],
    ],
    'flush' => true,
])->render();

Resultado

  • Item activo
  • Con badge 5
  • Item deshabilitado
  • Item success
