ButtonGroup

ButtonGroup agrupa botones horizontal o verticalmente. Soporta tamaños, aria labels para accesibilidad y barras de herramientas.

Codigo PHP

PHP
echo $bootstrap->buttonGroup([
    'buttons' => [
        ['content' => 'Izquierda', 'variant' => 'primary'],
        ['content' => 'Centro', 'variant' => 'primary'],
        ['content' => 'Derecha', 'variant' => 'primary'],
    ],
    'size'     => 'sm',
    'ariaLabel'=> 'Toolbar de edicion',
])->render();

Resultado


Opciones del Constructor

OpcionTipoDefaultDescripcion
buttonsarray—Array de configuraciones de botones (cada una con content, variant, etc.).
sizestring—Tamaño del grupo: lg, sm.
verticalboolfalseApilado vertical en lugar de horizontal.
ariaLabelstring—Etiqueta de accesibilidad para lectores de pantalla.
classstring—Clases CSS adicionales.
idstring—Identificador HTML del elemento.
