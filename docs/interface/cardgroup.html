CardGroup

CardGroup agrupa tarjetas con igual altura y bordes fusionados. Ideal para mostrar planes de precios o comparaciones.

Codigo PHP

PHP
echo $bootstrap->cardGroup([
    'cards' => [
        ['title' => 'Plan Basico', 'text' => 'Para empezar', 'footer' => '$9/mes'],
        ['title' => 'Plan Pro', 'text' => 'Profesional', 'footer' => '$29/mes'],
        ['title' => 'Plan Enterprise', 'text' => 'Sin limites', 'footer' => '$99/mes'],
    ],
])->render();

Opciones del Constructor

OpcionTipoDefaultDescripcion
cardsarray—Array de configuraciones de tarjetas (cada una con title, text, footer, etc.).
classstring—Clases CSS adicionales.
idstring—Identificador HTML del elemento.
