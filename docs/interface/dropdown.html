Dropdown

El componente Dropdown genera menus desplegables con items, divisores, cabeceras y soporte para iconos en cada opcion.

Codigo PHP

PHP
echo $bootstrap->dropdown([
    'label'   => 'Acciones',
    'variant' => 'primary',
    'size'    => 'sm',
    'items'   => [
        ['text' => 'Editar', 'url' => '#edit', 'icon' => 'edit'],
        ['text' => 'Duplicar', 'url' => '#dup', 'icon' => 'copy'],
        ['divider' => true],
        ['text' => 'Eliminar', 'url' => '#delete', 'icon' => 'trash'],
    ],
])->render();

Resultado

  • Editar
  • Duplicar
  • Eliminar
