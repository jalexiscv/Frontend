Button

El componente Button genera botones HTML con soporte para variantes (solid, outline), todos los tamaños (lg, md, sm), iconos, estado disabled y tipo (button/submit/reset).

Codigo PHP

PHP
echo $bootstrap->button([
    'content' => 'Guardar Cambios',
    'variant' => 'primary',
    'size'    => 'lg',
    'type'    => 'submit',
])->render();

// Boton con icono
$icon = Html::raw('<i class="fas fa-trash"></i>');
echo $bootstrap->button([
    'content' => [$icon, ' Eliminar'],
    'variant' => 'outline-danger',
    'size'    => 'sm',
])->render();
