Accordion

El componente Accordion genera paneles colapsables con animacion. Soporta modo flush (sin bordes) y alwaysOpen para mantener multiples paneles abiertos.

Codigo PHP

PHP
echo $bootstrap->accordion([
    'items' => [
        ['title' => 'Seccion 1', 'content' => 'Contenido del primer panel...'],
        ['title' => 'Seccion 2', 'content' => 'Contenido del segundo panel...'],
        ['title' => 'Seccion 3', 'content' => 'Contenido del tercer panel...'],
    ],
    'alwaysOpen' => false,
    'flush'      => true,
])->render();

Resultado

Contenido del primer panel: Aqui puedes configurar los parametros basicos del sistema.

Contenido del segundo panel: Personaliza la apariencia y el comportamiento de la interfaz.

Contenido del tercer panel: Opciones avanzadas para usuarios experimentados.

Opciones del Constructor

OpcionTipoDefaultDescripcion
itemsarray—Array de paneles (cada uno con title y content).
alwaysOpenboolfalsePermite mantener multiples paneles abiertos simultaneamente.
flushboolfalseEstilo sin bordes ni fondo (accordion-flush).
classstring—Clases CSS adicionales.
idstring—Identificador HTML del elemento.
