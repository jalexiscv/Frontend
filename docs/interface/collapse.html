Collapse

El componente Collapse permite ocultar/mostrar contenido mediante un boton o enlace toggle. Util para secciones de detalles, filtros avanzados o FAQs.

Codigo PHP

PHP
$trigger = $bootstrap->button([
    'content'          => 'Mostrar Detalles',
    'variant'          => 'outline-primary',
    'data-bs-toggle'   => 'collapse',
    'data-bs-target'   => '#detailsPanel',
]);
$content = $bootstrap->collapse([
    'id'      => 'detailsPanel',
    'content' => 'Informacion detallada que se expande al hacer click.',
    'show'    => true,
]);
echo $trigger->render() . $content->render();

Resultado

Informacion detallada que se expande al hacer click.
