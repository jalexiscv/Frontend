Card

El componente Card genera tarjetas con header, imagen (top/bottom), titulo, subtitulo, texto, lista y footer. Soporta variantes de color y alineacion.

Codigo PHP

PHP
echo $bootstrap->card([
    'title'        => 'Titulo de Tarjeta',
    'subtitle'     => 'Subtitulo secundario',
    'text'         => 'Contenido descriptivo de la tarjeta.',
    'image'        => '/img/header.jpg',
    'imagePosition'=> 'top',
    'header'       => 'Encabezado',
    'footer'       => 'Pie de tarjeta',
    'variant'      => 'primary',
])->render();

Opciones del Constructor

OpcionTipoDefaultDescripcion

subtitlestring—Subtitulo secundario.

imagestring—URL de la imagen.
imagePositionstringtopPosicion de la imagen: top, bottom.

footerstring—Contenido del pie de tarjeta.

idstring—Identificador HTML del elemento.
