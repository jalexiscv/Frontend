Spinner

El componente Spinner genera indicadores de carga con tipos border y grow. Soporta colores, tamaños y texto de accesibilidad.

Codigo PHP

PHP
echo $bootstrap->spinner([
    'type'    => 'border',
    'variant' => 'primary',
])->render();

echo $bootstrap->spinner([
    'type'  => 'grow',
    'variant' => 'success',
    'label' => 'Cargando datos...',
])->render();
