Badge

El componente Badge genera etiquetas y contadores. Soporta todas las variantes de color y el modo pill (redondeado).

Codigo PHP

PHP
echo $bootstrap->badge([
    'content' => 'Nuevo',
    'variant' => 'primary',
    'pill'    => true,
    'class'   => 'fs-6',
])->render();

Resultado

Primary Secondary Success Danger Warning Info Dark
Primary Pill Success Pill Danger Pill

Opciones del Constructor

OpcionTipoDefaultDescripcion
contentstring—Texto o contenido de la etiqueta.
variantstringsecondaryColor: primary, secondary, success, danger, warning, info, dark.
pillboolfalseForma redondeada (rounded-pill).
classstring—Clases CSS adicionales.
idstring—Identificador HTML del elemento.
