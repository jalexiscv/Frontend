Toast

El componente Toast genera notificaciones temporales con header, icono, timestamp y boton de cierre. Ideal para confirmaciones no bloqueantes.

Codigo PHP

PHP
echo $bootstrap->toast([
    'title'   => 'Archivo Guardado',
    'message' => 'El documento se guardo correctamente.',
    'time'    => 'Ahora',
    'icon'    => 'check-circle',
    'variant' => 'success',
])->render();

Resultado

Archivo Guardado Ahora
El documento se guardo correctamente.
