Modal

El componente Modal genera ventanas modales centradas con header, body y footer configurables. Soporta tamaños sm, lg, xl y modo scrollable.

Codigo PHP

PHP
$footer = [
    $bootstrap->button(['content' => 'Cancelar', 'variant' => 'secondary', 'data-bs-dismiss' => 'modal']),
    $bootstrap->button(['content' => 'Confirmar', 'variant' => 'primary']),
];
echo $bootstrap->modal([
    'id'       => 'confirmModal',
    'title'    => 'Confirmar Accion',
    'body'     => 'Esta seguro de que desea continuar?',
    'footer'   => $footer,
    'size'     => 'md',
    'centered' => true,
])->render();

Resultado

Confirmar Accion

Esta seguro de que desea continuar?
