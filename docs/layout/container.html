Container

El Container es el componente base para centrar y acolchar el contenido. Soporta variantes fixed y fluid.

Codigo PHP

PHP
use Higgs\Frontend\Frontend;
$frontend = new Frontend('bootstrap', '5.3.3');
$bootstrap = $frontend->get_Builder();

// Container fijo (ancho responsive)
echo $bootstrap->container([
    'content' => 'Contenido principal',
])->render();

// Container fluido (100% ancho)
echo $bootstrap->container([
    'content' => 'Contenido full-width',
    'fluid'   => true,
])->render();

Resultado

.container — Ancho maximo responsivo
.container-fluid — 100% del ancho
