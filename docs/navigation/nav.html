Nav

El componente Nav genera barras de navegacion con variantes tabs y pills. Los items pueden tener badges, estados active/disabled y soportan dropdowns anidados.

Codigo PHP

PHP
echo $bootstrap->nav([
    'type'  => 'tabs',
    'items' => [
        ['text' => 'Inicio', 'url' => '#', 'active' => true],
        ['text' => 'Perfil', 'url' => '#perfil'],
        ['text' => 'Mensajes', 'url' => '#msg', 'badge' => '3'],
        ['text' => 'Configuracion', 'url' => '#', 'disabled' => true],
    ],
])->render();
