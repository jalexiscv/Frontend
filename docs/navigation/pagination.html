Pagination

El componente Pagination genera controles de paginacion con numeros, enlaces anterior/siguiente y alineacion configurable.

Codigo PHP

PHP
echo $bootstrap->pagination([
    'current' => 3,
    'total'   => 10,
    'size'    => 'md',
    'align'   => 'center',
    'prevText'=> 'Anterior',
    'nextText'=> 'Siguiente',
])->render();

Resultado

  • 2

  • 10
