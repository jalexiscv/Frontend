Breadcrumb

El componente Breadcrumb genera caminos de navegacion jerarquica. Indica al usuario su ubicacion dentro de la aplicacion.

Codigo PHP

PHP
echo $bootstrap->breadcrumb([
    'items' => [
        ['text' => 'Inicio', 'url' => '/'],
        ['text' => 'Productos', 'url' => '/productos'],
        ['text' => 'Editar Producto #123', 'active' => true],
    ],
])->render();

Resultado

  1. Inicio
  2. Productos
  3. Editar Producto #123
